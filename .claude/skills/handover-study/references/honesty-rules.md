# 정직성 규칙 (handover-study 전 산출물 공통)

> 이 규칙은 도메인 지시보다 우선한다. 모든 정리본·퀴즈·플래시카드 생성에 적용.

1. **근거 인용**: 모든 핵심 주장(개념·동작·함수 역할)에 `file_path:line` 형식 근거를 붙인다.
   - 예: "세션 UID는 `ssi_00001` 형식으로 자동 생성된다 (`domain/board/models.py:42`)"
2. **미확인 표시**: 코드에서 직접 확인하지 못한 추정·전언은 "(미확인)"으로 명시한다. 그럴듯한 추측으로 빈칸을 메우지 않는다.
3. **날조 금지**: 존재하지 않는 함수·파일·수치·동작을 지어내지 않는다. 근거가 없으면 "근거 없음"으로 남긴다.
4. **한계 정직 보고**: 탐색하지 못한 영역·누락은 정리본의 "미확인 항목" 블록에 그대로 드러낸다.

## 적용 체크
- summary.md 의 모든 핵심 개념에 근거가 붙어 있는가?
- "미확인 항목" 블록이 비어 있다면, 정말 전부 확인했는가 — 아니면 누락을 숨긴 것인가?
- quiz-bank.md 의 정답·해설이 실제 소스와 일치하는가?
