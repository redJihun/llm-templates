# 간격반복 규칙 (단순 방식)

review-queue.md의 각 카드는 `연속정답`, `다음 복습 회차` 컬럼을 가진다. "회차"는 quiz 세션 카운트.

## 채점 후 갱신
- **오답**: 연속정답 = 0, 다음 복습 회차 = (현재 세션 + 1). 즉 다음 세션 즉시 재출제.
- **정답**: 연속정답 += 1, 간격 = [1, 3, 7][min(연속정답-1, 2)] 회차 뒤.
  - 연속정답 1 → 1회차 뒤, 2 → 3회차 뒤, 3+ → 7회차 뒤.
- 연속정답이 3 이상이고 정답이면 큐에서 제거 가능 (숙지완료로 간주).

## 출제 우선순위
1. review-queue.md에서 `다음 복습 회차 <= 현재 세션`인 카드 우선.
2. 부족분은 quiz-bank.md에서 미출제 문제로 채움.

## 세션 카운트
progress.md에 scope별 누적 quiz 세션 수를 기록하거나, review-queue.md 상단에 `현재 세션: N` 기록.
